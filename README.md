# Odd or Even Game

## About the Game

Odd or Even is a simple two-player game built using HTML, CSS, and JavaScript.

Each player selects a number between 1 and 10 and chooses either Odd or Even.

The two numbers are added together:

- If the sum is Even, the player who selected Even wins.
- If the sum is Odd, the player who selected Odd wins.
- If both players selected the resulting option, there is no winner.

## How to Play

1. Player 1 selects a number from 1 to 10.
2. Player 1 chooses Odd or Even.
3. Player 2 selects a number from 1 to 10.
4. Player 2 chooses Odd or Even.
5. Click the PLAY button.
6. The game calculates the sum and displays the result.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Start playing!
